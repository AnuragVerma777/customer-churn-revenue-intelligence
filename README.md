# Customer Churn & Revenue Intelligence

An end-to-end machine learning project that predicts customer churn and transforms customer data into actionable revenue insights through an interactive Streamlit dashboard.

## 🚀 Overview

Customer churn is one of the major challenges faced by subscription-based and customer-centric businesses.

This project uses machine learning to identify customers who are likely to churn and provides insights into the potential revenue impact of customer churn.

The interactive dashboard allows users to:

- Predict customer churn
- Analyze customer behavior
- Understand important churn factors
- Estimate potential revenue impact
- Explore customer-level insights
- Visualize key business metrics

## ✨ Features

- 📊 Interactive Streamlit dashboard
- 🤖 Machine learning based churn prediction
- 📈 Customer and revenue analytics
- 🔍 Exploratory Data Analysis (EDA)
- 🎯 Customer-level churn probability
- 💰 Revenue impact analysis
- 📌 Key performance metrics
- 📉 Visual insights and business intelligence
- ⚡ Fast and interactive predictions
